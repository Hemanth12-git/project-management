# Project Management Application

A full-stack project management application that helps teams organize projects, manage people, and track tasks efficiently — all in one place.

## About

This application provides a centralized platform for managing the entire lifecycle of your projects. You can create and oversee multiple projects, onboard team members, assign tasks, and monitor progress through an intuitive interface.

**Key capabilities:**
- Create and manage multiple projects
- Add and manage people / team members
- Create, assign, and track tasks within projects
- Clean, responsive UI for a smooth experience

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript |
| Backend | Node.js, TypeScript |
| Database | MongoDB |
